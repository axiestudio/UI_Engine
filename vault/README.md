# vault — UI preset
**Job:** make an honest price *look* honest — a ledger that adds up in front of the reader. **Emotion:** quiet abundance; a receipt you'd proudly frame.
**Signature move:** the receipt prints itself — dashed perforation edges, mono lines dropping in sequence (`motion` stagger), and the total arrives last with a rubber-stamp settle (rotate −8 → −2, spring bounce → perfect stillness).
**Details:** `bg-muted/40` section, `role` semantics on the list, print-safe statics under reduced motion. Provenance: wm `card`/`badge`/`button`, mp `text-loop`, `in-view`.
