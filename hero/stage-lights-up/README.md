# stage-lights-up

House-lights ramp hero: three spot cones converge on the headline, then snap off and the band settles into a reveal

**Dual-surface preset** — one props-driven component that reads as a website *section* and as a webapp *feature*. The engine view exposes a `SECTION | FEATURE` toggle over real demo content for each.

Category `hero` · motion via `motion/react` · brand tokens in `src/index.css` (`:root` + `.dark`).

## Build

From repo root: `npm run build:stage-lights-up` · engine wires it via the `file:` dependency.

MIT · handcraft kit vendored where used · see `UI/VENDORING-STRATEGY.md`.
