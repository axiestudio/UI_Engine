# display-anti-design — UI preset

Anti-design fashion-drop hero in the **Display / Anti-design** visual direction (unslop.site reference). Oversized Archivo Black 900 display type (solid + outlined), a cream `#fff5e1` surface with electric-yellow `#ffea4d` and hot-pink `#ff3b6f` clash, square ink rules, one pink pill accent, cropped out-of-frame type. Props-driven, token-only, responsive.

**Design reference:** https://unslop.site/reference/display-anti-design

```tsx
<DisplayAntiDesign
  brand="RIOT*"
  titleA="LOUD"
  titleB="& UGLY"
  pill="New drop"
  primaryCta={{ label: "Shop the drop →" }}
/>
```
