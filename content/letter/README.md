# letter — UI preset

The newsletter that arrives like post — stamp, greeting serif, blur-to-focus reveal (Watermelon newsletter base + Motion-Primitives)

**Provenance:** composed from the matured registry sources vendored in-repo (Motion Primitives, Watermelon UI, shadcn/ui, React Bits). This preset carries no handcrafted primitives — every interaction is library-backed.

```tsx
import { Letter, Newsletter1, ProgressiveBlur, InView, Badge, Button } from "letter"

<Letter />
```
