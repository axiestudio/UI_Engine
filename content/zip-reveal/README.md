# zip-reveal

Drag-zip package: a real zipper track opens on drag/scrub to release the drop contents

**Dual-surface preset** — one props-driven component that reads as a website *section* and as a webapp *feature*. The engine view exposes a `SECTION | FEATURE` toggle over real demo content for each.

Category `content` · motion via `motion/react` · brand tokens in `src/index.css` (`:root` + `.dark`).

## Build

From repo root: `npm run build:zip-reveal` · engine wires it via the `file:` dependency.

MIT · handcraft kit vendored where used · see `UI/VENDORING-STRATEGY.md`.
