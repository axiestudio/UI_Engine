# DeviceResponsive

Website section — part of the **device stage** family (desktop / mobile / tablet / laptop / responsive).

- **JOB** show the product on real hardware, not a floating rectangle
- **SIGNATURE** see the component header (each device has one move)
- **TOKENS** shadcn token set only; device hardware stays deliberately black like physical units
- **A11Y** keyboard-operable controls (`device-responsive` is a real `role="slider"`), `prefers-reduced-motion` honored, focus-visible rings
- **USE** hero or proof section; pass `src` for screenshots or `children` to render live screen content
