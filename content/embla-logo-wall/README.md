# embla-logo-wall — UI preset

Infinite logo loop marquee, grayscale to color on hover

**Provenance:** composed from the matured registry sources vendored in-repo (Motion Primitives, Watermelon UI, shadcn/ui, React Bits). This preset carries no handcrafted primitives — every interaction is library-backed.

```tsx
import { EmblaLogoWall, InView } from "embla-logo-wall"

<EmblaLogoWall />
```
