# countdown-flare

Launch clock with ignition: LED digits burn down to T-0, the horizon lifts with an exhaust flash

**Dual-surface preset** — one props-driven component that reads as a website *section* and as a webapp *feature*. The engine view exposes a `SECTION | FEATURE` toggle over real demo content for each.

Category `commerce` · motion via `motion/react` · brand tokens in `src/index.css` (`:root` + `.dark`).

## Build

From repo root: `npm run build:countdown-flare` · engine wires it via the `file:` dependency.

MIT · handcraft kit vendored where used · see `UI/VENDORING-STRATEGY.md`.
