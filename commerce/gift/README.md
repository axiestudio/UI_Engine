# gift — UI preset
**Job:** gift a service to someone not in the room. **Emotion:** generous warmth, hand-picked not checkout-adjacent.
**Signature move:** the card flips like real card stock — the message is written on the *back*, because that's where gifts explain themselves. Hover (desktop) tap (touch); reduced-motion shows front + offset back side-by-side.
**Details:** embossed-style mono serial line, dashed "gift card" chip, amount radiogroup, Magnetic CTA, safe copy `Wrap it` (host wires `onGift`). Provenance: wm `card`/`badge`/`button` kits, mp `in-view`, `magnetic`; flip utilities added in index.css (`backface-hidden`, `rotate-y-180`).
