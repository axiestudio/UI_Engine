# finale-confetti

Celebration overlay: confetti bursts from a banner line; trigger- or auto-fired, self-clearing

**Dual-surface preset** — one props-driven component that reads as a website *section* and as a webapp *feature*. The engine view exposes a `SECTION | FEATURE` toggle over real demo content for each.

Category `chrome` · motion via `motion/react` · brand tokens in `src/index.css` (`:root` + `.dark`).

## Build

From repo root: `npm run build:finale-confetti` · engine wires it via the `file:` dependency.

MIT · handcraft kit vendored where used · see `UI/VENDORING-STRATEGY.md`.
