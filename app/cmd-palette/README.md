# cmd-palette

⌘K command palette — fuzzy search, grouped commands, recents, inline calc, keyboard-first

**Webapp-primary preset** — built for product surfaces first (panel, cell, overlay, input); on a website it powers the “real product” demo sections.

Category `app` · shared APP SYSTEM brandkit tokens (--ok/--warn/--err/--info, --app-line, --app-code) · motion via motion/react · cmdk-backed listbox

## Build

From repo root: `npm run build:cmd-palette`.
